三、选定编号后，在它内部再做一层小变化

★★ 这是**电商详情页模块**，不是生活方式摄影：产品是主角。但场景要**布置得丰富**——
  画面边缘要像造型师的桌面一样有层次、有东西，不能光秃秃。
  **每轮用 4-6 件道具**，全部贴着画面边缘、**大部分被画面裁掉**，只露一角或一条边，
  可以互相轻微叠着、处在不同远近。**它们不许进到构图中间、不许压到产品、不许比产品抢眼。**
  也不许写窗棂光条、椅背、墙面、房间、植物——丰富感来自桌面上的道具，不是来自展示一个房间。
  （手不归你管，由需求卡① 的 `Hand` 字段决定，你别写。）
★ 每轮换一两样，别全换：

      一摞叠起来的书 / 黑白细条纹针织或钩织布 / 藤编一角 / 米白小卡片 / 亚麻餐巾一角 /
      哑光素色陶杯 / 深木小圆盘 / 素色玻璃小瓶 / 一段米白丝带。
    · 浅调组（9-10）的池子：白色书或杂志（封面只有细线描简笔插画 + 一行细体外文）/
      素白护肤软管（只露下半段）/ 白色键盘一角（键帽无任何品牌标）/ 磨砂素色玻璃小瓶（瓶身留白）/
      白底蓝字的外文书 / 黑白细条纹织物一角 / 折叠的本白棉布 / 哑光米白陶杯 / 米白小卡片。
    **全部无品牌名、无 logo、无可辨认商标。**
  - **每件贴哪条边被裁**（左上/右上/右缘/左下/右下之间轮换）
  - **主光从哪一侧进来**（左前侧 / 右前侧 / 左后侧 / 右后侧）
  - **光的时间感**（清晨清透 / 午后偏暖 / 傍晚低角度）
  - **托盘/垫板要不要出现**，以及产品压在它上面还是直接躺台面（浅调组默认不用托盘，产品直接躺织物上）
  - **台面材质自身的细节**（木纹深浅走向 / 石纹疏密 / 绒面方向 / 布纹粗细 / 针织罗纹的粗细与走向）
★ 不许变的，**按调性分两套，照本轮 TONE 执行那一套**：
  · `TONE: DARK` → **台面必须明显比产品深**（浅木、白大理石、浅水泥、米白床品一律不行——
    浅色产品会陷进浅台面，这是商家驳回过的"老式"观感的主因）。
  · `TONE: LIGHT` → **台面是奶白/米白的柔软织物，明度接近产品，这是故意的，不许自作主张压深。**

    ① 台面是粗糙有绒毛的针织/棉织，与产品光滑面料形成强烈质感对比
    ② 产品四周有清晰可辨的柔和接地阴影，织物在产品下方微微凹陷
    ③ 平滑的白色大面积物件（书页、白纸、白瓷）只放在远离产品的画面角落，不许紧贴产品边缘
  · 两套共同：**不许写"无道具"**。
